# E-commerce-Data-Analysis
E-commerce-Data-Analysis using Python

Project Overview

This project focuses on analyzing an e-commerce Superstore dataset using Python. The analysis includes data loading, data cleaning, date transformation, exploratory data analysis, and sales and profit visualization.

Dataset

The dataset contains 9,994 rows and 21 columns.

Key columns include:

- Order Date
- Ship Date
- Ship Mode
- Customer Name
- Segment
- Country
- City
- State
- Region
- Category
- Sub-Category
- Sales
- Quantity
- Discount
- Profit

Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

Project Steps

1. Data Loading

Loaded the Superstore dataset using Pandas.

2. Data Cleaning

- Checked for missing values
- Checked for duplicate rows
- Checked data types

The dataset contained no missing values and no duplicate rows.

3. Data Transformation

Converted:

- "Order Date" to datetime
- "Ship Date" to datetime

Created:

- Order Month
- Order Year
- Order Day of Week

4. Exploratory Data Analysis

Performed:

- Monthly Sales Analysis
- Sales Analysis by Category
- Sales Analysis by Sub-Category
- Monthly Profit Analysis
- Profit Analysis by Category
- Profit Analysis by Sub-Category

Key Insights

- Technology had the highest sales among the three categories.
- Technology also generated the highest total profit.
- November had the highest monthly sales.
- December had the highest monthly profit.
- Chairs and Phones were among the highest-selling sub-categories.
